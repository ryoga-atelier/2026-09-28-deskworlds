# 仕上げの意図と判定基準

依頼：本物らしい、可愛いグッピーの水槽を普段のMacの背景として楽しむ。見た目の判定も担当が引き受ける。

- 写実的な小さな眼、口、腹の量感、尾柄からつながる柔らかい尾。横・斜め・正面・旋回で破綻しない。
- 半透明の鰭、個体ごとの違い。反復模様や切り抜き感を抑える。
- 進む／漂う／曲がるが分かれ、体幹から鰭へ遅れて伝わる泳ぎ。
- 水草の密度・葉の大きさ・砂・陰影・魚の前後関係を同じ水槽として整える。
- 普段の画面サイズで点検し、拡大静止画だけで完成を判定しない。
- 餌、停止／再開、カーソル、設定保持、起動登録、負荷、元に戻す経路を点検する。

参照は REFERENCES.md と VISUAL-REVIEW.md。実写資料は観察用。素材の生成由来は同梱して残す。操作の実測・コード確認・未確認を区別する。

## v12の修正条件

後景の黒つぶれを解消し、水の奥行きと葉の輪郭が分かる昼間の水槽へ。魚・砂・石を白飛びさせず、画面全体への一律の露出増加は避ける。水草・石・流木の位置は維持し、魚やエビを背景へ焼き込まない。実画面と生成素材を見比べ、未確認操作を再点検する。

## v13: 透明な青い水と水槽の動き

ユーザー訂正：灰緑の背景は黒板消しのように見える。透明度の高いミネラルウォーターのような青い水。水面のさざ波、水草の揺れ、底近くで魚に反応して薄く舞う砂、循環口から上がる小さな泡を動かす。魚のない静止画を背景として置くだけで完了にしない。強い全画面歪み、白い濁り、常時の砂嵐を避け、停止と被覆時には動きを止める。実機映像・負荷・入力で確認する。

## v14: 明るい多彩な体色と肉付き

承認済み：淡い明色18匹＋赤3・濃青3。暗い素材・陰側の照明・細い前腹部を調整する。背景v13と動きを保ち、全景と全周回転で明度・厚み・8色の識別を判定する。根拠：利用者の具体的な違和感と承認計画、コードの減光係数、制作工程 plan-design-task の受入証拠→依存順。v13の実機負荷を再測定し、変更後と同じ露出条件で照合する。実操作待ちは合格にせず記録する。
