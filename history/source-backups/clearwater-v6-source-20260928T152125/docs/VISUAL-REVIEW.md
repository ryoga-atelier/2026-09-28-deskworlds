## 手を入れた箇所と比較で確認したこと

1. 胴体断面をテトラ由来の一律縮小から、低い頭頂・前寄りの腹・細長い尾柄へ変更。口先を上げ、エラの溝と銀色の境界を弱めた。初回候補には頭の別部品感が残ったため再調整した。
2. 尾の先まで背骨を曲げる変形をやめ、尾柄を支点に自由な膜として変形。泳ぎの力・曲がる向き・位相に追従し、余韻と開閉を加えた。18段の膜メッシュと実際に変形した面の法線で照明を計算する。色・深度の両パスは同じ変形を共有。
3. 同一個体の色・模様を保持。金色の大きな黒斑を細かくし、頭の白いハイライトと体のシアン線を弱めた。胸びれは個体のcharacterに応じた周期。低周波の膜の動きが位相2πごとに跳ばないよう長周期で折り返す。
4. 水草の帯状の葉を細くし、左右に細かい葉の群落を増やした。中景の高さを増し、中央の砂地と遊泳空間を残した。背面の明るさと色、浮遊物を抑えた。

## 到達点と残る差

尾の板らしさ、頭の不自然に明るい銀色と硬いエラ境界、太い草が並ぶ単調さは比較で改善。正面・斜めの形と、実際の泳ぎも確認した。

ただし、実写と見分けがつかないグッピーの再現には届いていない。拡大すると体色が滑らかで、鱗の模様・尾の斑紋は手続き生成の規則性が見える。眼やエラの細かな生体運動、尾の流体との相互作用は簡略化されている。植栽の奥行き構成を変えたが、背景の平面性や細い葉の画素のちらつきも残る。泳ぎの速度・加速の係数は上流由来で、実魚動画との定量一致は未実施。

構文検査・実行テストが成功したことと、実物らしさの達成を同じ意味には扱わない。
