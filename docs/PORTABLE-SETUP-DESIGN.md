# Macを主とする、リンクからのセットアップ

利用者の依頼は、同じGitHubをClaude Code・Codexへ渡すだけで、対象OSに応じてセットアップを進められる状態にすること。2026-09-30の追加指示で、招待不要の公開配布へ変更した。採用済みの魚・24匹・8色・24fps・水景を保つ。

- Macは既存のSwift/WKWebViewアプリと削除しないインストーラーを再利用する。
- Windowsは無料のLively Wallpaper 2.2以降をホストにする。原本から同じ魚を組み立て、ローカルフォルダーだけで動くZIPにする。ES Modulesの独自スキーム依存を避け、ビルド時に単一の通常スクリプトへまとめる。画像の参照元は各モジュールの位置を保つ。
- Livelyの再生通知と「泳ぐ」の設定を別々に保つ。ホストが復帰しても本人の一時停止を解除しない。新しい定期タイマーは追加しない。
- Windowsの導入は既存のLivelyライブラリを読み取り、新しい専用フォルダーを作る。他の壁紙、グローバル設定、OS設定は変更しない。CLIの送信成功と実画面での描画成功を分ける。
- MacとWindows用の入口、依存の診断、エラー時の復帰、アンインストール、AI向けの完了判定を同じリポジトリへ入れる。
- テストは復元・ビルド、既存検査、ブラウザーでの描画と停止、Windows/MacのCI。実Windowsデスクトップと再ログイン等は実測がなければ未確認のまま記録する。

独自部分の権利と第三者のライセンスを保持する。GitHubの可視性は本人指示によりPUBLIC。導入先の資格情報・権限・外部課金を自動で変更しない。
