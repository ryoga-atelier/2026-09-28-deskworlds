# ブラウザの裏に水槽を保つ修正（2026-09-30）

魚の採用版は `bronze-gradient-guppy-v29-r16` のまま、Macの表示管理を `retained-frame-v1` に更新しました。WindowsのLively橋渡しと配布ZIPは変更していません。

## 原因と変更

約85%以上がウィンドウに覆われた画面は、従来から省電力のため0fpsになります。r15ではその状態が60秒続くとWKWebViewを外し、ウィンドウの内容も空にしていました。少し見えている縁まで水槽が消えるのが問題でした。

修正版では、描画済みの水槽を静止画として残してからWebViewを手放します。戻る時も静止画の裏でページを読み込み、水槽が描画されてローディング表示が消えた後に切り替えます。静止画を取得できない時は停止中のページを残し、再読み込みが失敗しても静止画を残します。可視状態が変わった後に古い非同期処理が表示を消すことも防ぎます。

静止画は最大180万画素。RGBA画素そのものは1画面約6.9MiB以下です。これはアプリ全体の実メモリではなく、AppKitやGPUが持つ表示用コピーなどは別途必要です。混在する画面の倍率によってWebKitの取得画像が大きくなることを実機で観測したため、取得指定に加えて保存前にも画素数を制限しています。停止中に描画を回し続ける方式ではありません。

魚・水景・24匹・8色・Balanced・24fps・カーソル操作の設定、元のmacOS壁紙とアクセシビリティ設定は維持します。上流の固定版は変更せず、ビルド用Swiftだけに適用します。

## 検査

`python3 scripts/check-native-retained-frame.py` はMacの実際のAppKit/WKWebViewを使います。デスクトップセッションが必要です。テスト用コピーだけ休止待ちを0.5秒に縮め、配布アプリは60秒のままです。

確認済みの12項目:

- 4K入力も180万画素以内に保存。
- 通常のPauseはページを保持。
- 被覆によるページ解放時も画像を表示。
- 静止画にキャンバスの実画素が入り、画素上限を守る。
- 再読み込み中のページを静止画の下に配置。
- コールバックの登録だけではローディング中のページを見せない。
- 初回描画後に静止画を外す。
- 再表示時に予約済みの解放を取り消す。
- 未描画のページは画像取得の代わりにそのまま保持。
- 繰り返しの解放でも画像を保持。
- ページ読み込み失敗時も画像を保持。
- 終了時に予約を取り消し、ウィンドウを再出現させない。

既存のPython検査5件、Windows橋渡し検査3件、`setup.py verify`（構文・上流・魚・形状・水の検査）も成功。ネイティブのビルド・署名検査後に、元MacのアプリとLaunchAgentをrollbackへ保存退避して導入しました。導入前後の魚の版・素材・水景のハッシュは一致しています。

## 実機確認の範囲

実際の60秒の待機後に、両画面のページ解放と水槽の静止画保持をアプリのログで確認しています。保存画像は1512×982と1788×1006で、双方とも180万画素以下です。導入済みSwiftのSHA256は `08ade7f7db3f0172f8cf1ca5f7fdc1f58da21768a6fc43e7110267a87749a4e5`。再表示時の実デスクトップ確認は、作業時にMacがロックされたため解除待ちです。上記のネイティブ検査は実画面での確認を代替したという意味ではありません。

実スリープ・再ログインや、今回の版での90秒×各状態のCPU/GPU比較・30分連続測定は再実施していません。以前の負荷測定値を今回の実測値として扱いません。

## 再確認方法

1. `python3 setup.py install` で導入し、水槽が見えることを確認。
2. ブラウザを画面の大部分に広げ、砂や水草の縁を少し残して70秒待つ。
3. 残した縁が水槽の静止画のままで、元の壁紙へ切り替わらないことを確認。
4. ブラウザを小さくする。水槽を残したまま読み込み直し、魚が再び泳ぐことを確認。
5. ログの `released hidden scene page; retained aquarium frame` → `reloading scene page after release; retaining aquarium frame` → `fresh aquarium frame visible` を照合。

SIGUSR2の受動診断は、休止中には `pageReleased: true`、`retainedFrame: true`、`retainedPixels` を出します。SIGUSR1は上流の強制描画付き撮影なので、休止を保った検証には使いません。
